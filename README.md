# Java Data Structures & Algorithms

A personal learning repository where I implement core data structures from scratch in Java to understand how they work under the hood — focusing on behavior, edge cases, and time/space complexity rather than using built-in library classes.

## Implemented

### Linked Lists (`data-structures/linked-lists/`)
- **Singly Linked List** and **Doubly Linked List**, built from scratch using object-oriented design
- Core operations: insertion, deletion, traversal, reversal, and position-based updates
- Uses a dummy head node and a tail pointer to simplify edge cases and speed up insertions/deletions at the list ends
- Time and space complexity documented for each operation
- Includes runnable demo files (`SinglyLinkedListDemo.java`, `DoublyLinkedListDemo.java`)
